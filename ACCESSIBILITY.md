# Accessibility Statement for Toolz Downloadz

Toolz Downloadz provides an accessible web interface for downloading media.

- **Keyboard Usable**: Input fields, format chips, and download buttons can be operated using `Tab`, `Enter`, and `Space`.
- **Contrast**: Text and UI elements are styled with high-contrast colors against dark surfaces.
- **Screen Reader Announcements**: Download progress and extraction status use semantic markup and live region states.

If you encounter accessibility issues, contact **frerox.toolz@gmail.com**.
