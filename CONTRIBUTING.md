# Contributing to Toolz Downloadz

Toolz Downloadz is the Next.js 15 web client for downloading media via `toolz-downloadz-api`.

## Guidelines & Legal Rules

1. **Lawful Archiving**: Only features intended for personal, non-commercial archiving of authorized media will be accepted. No DRM circumvention.
2. **License**: Contributions are submitted under the **GNU General Public License v3.0 (GPL-3.0)**.
3. **Secrets**: Never commit API keys or secret tokens into client components.

## Local Dev

```bash
git clone https://github.com/freroxx/toolz-downloadz.git
cd toolz-downloadz
npm install
cp .env.local.example .env.local
npm run dev
npm run build
```

## Security

Report vulnerabilities privately to **frerox.toolz@gmail.com** (see [SECURITY.md](SECURITY.md)).
